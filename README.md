# Math Challenge

A console-based mathematical quiz game developed using **C++** for the Algorithm Design and Analysis Lab course.

## Features
- Random Math Questions
- Three Difficulty Levels (Easy, Medium, Hard)
- Four Arithmetic Operations (+, -, *, /)
- Score Tracking
- Question History
- Leaderboard
- Player Search

## Algorithms & Data Structures
- **Vector:** Stores player records.
- **Stack:** Stores question history.
- **Merge Sort:** Sorts leaderboard.
- **Linear Search:** Searches for players.
- **Random Number Generation:** Generates questions.

## Technologies
- C++
- STL
- GCC Compiler

## How to Run

```bash
g++ math.cpp -o math
.\math
```
